# ◈ A.T.L.A.S. — Intelligence System
**Advanced Tactical Learning And Search**

ATLAS is a premium, multimodal AI assistant designed for Windows power users. Built on the Gemini 2.5 architecture, it combines real-time voice interaction, vision-based screen analysis, and deep system integration.

## 🚀 Launch Readiness
1. **Initial Setup**: Run `diagnostics.py` to ensure your microphone, camera, and API keys are correctly configured.
2. **First Boot**: Execute `Start_ATLAS.bat`. You will see a cinematic boot sequence.
3. **Activation**: Press `[F7]` to toggle the microphone. ATLAS will greet you in your selected language once connected.

## ✨ Premium Features
- **Visual Core v2**: High-fidelity AI interface with glassmorphism and real-time audio reactivity.
- **Multimodal Vision**: "What's on my screen?" — ATLAS captures and analyzes your display in real-time.
- **WhatsApp Automation**: Auto-responder for calls using virtual audio routing (VB-Cable).
- **Persistent Memory**: Remembers your preferences, identity, and personal facts across sessions.
- **Smart Tools**: Deep integration with Steam, Browser, Computer Settings, and File Management.

## 🛠 Diagnostics
If you encounter connection or hardware issues, run:
```bash
python diagnostics.py
```

## 📜 Legal & Safety
- **Classified**: For personal use only.
- **Failsafe**: Use `Ctrl+C` in the terminal to force shutdown.
- **Privacy**: All memory is stored locally in `memory/long_term.json`.
